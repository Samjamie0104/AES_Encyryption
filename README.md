# AES Encryption

A simple C project using CMake for AES encryption.

## Building

1. Ensure CMake and a C compiler (e.g., GCC or MSVC) are installed.
2. Run `cmake .` in the root directory to configure.
3. Run `cmake --build .` to build.

Or use the VS Code task: Ctrl+Shift+P > Tasks: Run Task > Build Project

## Running

Execute the built executable: `./build/Debug/aes_encryption.exe` (on Windows)
